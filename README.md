# Bob 通用 AI 处理器

基于自定义提示词对任意文本进行智能处理，而非传统翻译。特别适合代码学习、文本分析、知识提炼等场景。

支持**划词处理**和**OCR 后处理**，与 Bob 原生快捷键工作流完全兼容。

**版本**：v0.2.0  
**更新时间**：2026-05-30 11:20:00  
**仓库**：https://github.com/gray0128/bob-Universal-Plugin

---

## 核心能力（v0.2.0）

- **6 个高质量内置模板**：代码解释、安全审计、文章提炼、知识卡片、加注释、Bug 分析（可一键选择）
- **原生支持主流思考模型**：
  - DeepSeek-R1 / Reasoner
  - Qwen3 / QwQ
  - Claude 3.7/4 Thinking
  - Gemini 2.5 Thinking
  - OpenAI o1/o3/o4 系列
- **思考等级控制**：关闭 / 低 / 中 / 高 / 自动（自动适配各厂商参数）
- 支持 OpenAI、DeepSeek、Claude、Qwen、Gemini、Ollama 等几乎所有兼容接口
- 流式输出 + 思考过程完整显示（thinkInfo）
- 与 Bob 截图 OCR 快捷键无缝配合

## 推荐使用场景与 Prompt 示例

### 场景一：代码深度解释（默认推荐）

**System Prompt**：
```
你是一位经验丰富的软件工程师和编程导师，专注于帮助开发者深入理解代码。

回答必须使用简体中文，结构严谨：
1. 一句话核心目的
2. 关键逻辑拆解（逐段/逐行重要部分）
3. 设计意图与权衡
4. 潜在问题与改进建议
5. 学习要点总结
```

**User Prompt 模板**：
```
请深入分析并解释以下代码/文本，便于我学习：

```
$text
```

请严格按以下结构输出：
- **核心目的**：一句话说明
- **实现拆解**：按执行顺序或模块拆解关键逻辑
- **设计亮点**：值得学习的点
- **潜在风险**：bug、安全、性能问题
- **学习建议**：下一步可以深入的方向
```

### 场景二：技术文章 / 文档提炼要点

**User Prompt 模板**：
```
请阅读以下内容，提炼出**核心知识点**和**可立即应用的实践建议**，适合我记录到笔记中：

$text

输出格式：
## 核心概念（3-5 点）
## 关键洞见
## 立即可做的行动项
## 可能踩的坑
```

### 场景三：代码安全审计

**User Prompt 模板**：
```
你是一名资深安全工程师。请对以下代码进行安全审查，重点关注 OWASP Top 10 风险、注入、权限、敏感信息泄露等问题。

$text

请列出所有发现的风险点，并给出修复建议。
```

### 场景四：把代码转成带详细注释的版本

**User Prompt 模板**：
```
请为以下代码添加**高质量中文注释**，注释要解释"为什么"而非"做了什么"。保持代码可运行，只增加注释。

```
$text
```
```

## 如何实现"多个不同动作"（重要）

Bob 不支持一个插件同时注册多个服务，但推荐做法是：

1. 在 Bob「服务」列表中**多次添加「通用 AI 处理器」**
2. 每次添加时起不同的**服务名称**（如「代码解释」「要点提炼」「安全审计」）
3. 分别配置不同的 System Prompt / User Prompt 模板

这样你就可以拥有多个专职的 AI 处理动作，并为它们设置独立的快捷键。

示例：
- 「代码解释」→ 配置解释型 prompt
- 「知识卡片」→ 配置提炼型 prompt
- 「转 Python」→ 配置代码转换型 prompt

## OCR 工作流（截图自动处理）

Bob 支持「截图后自动调用某个翻译服务」：

1. Bob 设置 → 快捷键 → 截图翻译 → 选择你配置好的「通用 AI 处理器」（或「代码解释」服务）
2. 使用截图快捷键后，Bob 会自动 OCR → 调用本插件 → 显示解释结果

与划词处理完全一致，无需额外配置。

## 高级配置建议

- **本地模型（Ollama / LM Studio）**：推荐 `qwen2.5-coder:14b`、`deepseek-r1:14b` 等，temperature 设 0.2-0.4
- **Reasoning 模型**（DeepSeek-R1、Qwen3、o1 系列）：插件会自动提取 `reasoning_content` 并显示在 Bob 的「思考过程」区域
- **Temperature**：代码/分析类任务建议 ≤ 0.4，创意重写可提高到 0.8
- **Max Tokens**：复杂代码建议 3000+，注意模型上下文长度限制

## 变量列表

在 User Prompt 模板中可使用以下变量：

| 变量            | 含义                        |
|-----------------|-----------------------------|
| `$text`         | 用户选中的原文（最重要）    |
| `$from`         | 用户选择的源语言            |
| `$to`           | 用户选择的目标语言          |
| `$detectFrom`   | Bob 实际检测到的源语言      |
| `$detectTo`     | Bob 实际检测到的目标语言    |
| `$date`         | 当前日期（YYYY-MM-DD）      |
| `$time`         | 当前时间                    |

## 开发与调试

- 直接修改 `main.js` 和 `info.json` 后，在 Bob 插件管理中「重新加载」即可生效
