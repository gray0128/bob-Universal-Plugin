# Bob 通用 AI 处理器

基于自定义提示词对任意文本进行智能处理，而非传统翻译。特别适合代码学习、文本分析、知识提炼等场景。

支持**划词处理**和**OCR 后处理**，与 Bob 原生快捷键工作流完全兼容。

**版本**：v0.1.0  
**更新时间**：2026-04-22 10:30:00

---

## 核心能力

- 完全自定义 System Prompt + User Prompt 模板
- 支持 OpenAI、DeepSeek、Claude、Ollama、硅基流动、火山方舟等所有兼容接口
- 支持流式输出 + Reasoning 模型思考过程显示（thinkInfo）
- 内置针对**代码学习**优化的默认提示词
- 变量替换支持：`$text`（核心）、`$from`、`$detectFrom` 等
- 与 Bob 截图 OCR 快捷键无缝配合，实现"截图 → 自动解释"一条龙

## 快速开始

### 1. 安装

1. 下载本插件（打包为 `.bobplugin` 后双击安装，或开发时直接把文件夹拖入 Bob 插件目录）
2. Bob 设置 → 服务 → 添加服务 → 选择「通用 AI 处理器」

### 2. 基础配置（最低可用）

| 配置项          | 示例值                              | 说明 |
|-----------------|-------------------------------------|------|
| API Base URL   | `https://api.deepseek.com/v1`      | 必填，Ollama 填 `http://localhost:11434/v1` |
| API Key        | `sk-xxxx`                          | 本地模型可留空 |
| 模型名称       | `deepseek-chat`                    | 推荐 `deepseek-chat` / `qwen2.5-coder` / `gpt-4o-mini` |
| User Prompt 模板 | （见下方默认值）                   | **必须包含 `$text`** |

配置完成后即可使用：选中代码 → 选择本服务 → 获得结构化解释。

## 推荐使用场景与 Prompt 示例

### 场景一：代码深度解释（默认推荐）

**System Prompt**：
```
你是一位经验丰富的软件工程师和编程导师，专注于帮助开发者深入理解代码。

回答必须使用简体中文，结构严谨：
1. 一句话核心目的
2. 关键逻辑拆解（逐段/逐行重要部分）
3. 设计意图与权衡
4. 潜在问题与改进建议
5. 学习要点总结
```

**User Prompt 模板**：
```
请深入分析并解释以下代码/文本，便于我学习：

```
$text
```

请严格按以下结构输出：
- **核心目的**：一句话说明
- **实现拆解**：按执行顺序或模块拆解关键逻辑
- **设计亮点**：值得学习的点
- **潜在风险**：bug、安全、性能问题
- **学习建议**：下一步可以深入的方向
```

### 场景二：技术文章 / 文档提炼要点

**User Prompt 模板**：
```
请阅读以下内容，提炼出**核心知识点**和**可立即应用的实践建议**，适合我记录到笔记中：

$text

输出格式：
## 核心概念（3-5 点）
## 关键洞见
## 立即可做的行动项
## 可能踩的坑
```

### 场景三：代码安全审计

**User Prompt 模板**：
```
你是一名资深安全工程师。请对以下代码进行安全审查，重点关注 OWASP Top 10 风险、注入、权限、敏感信息泄露等问题。

$text

请列出所有发现的风险点，并给出修复建议。
```

### 场景四：把代码转成带详细注释的版本

**User Prompt 模板**：
```
请为以下代码添加**高质量中文注释**，注释要解释"为什么"而非"做了什么"。保持代码可运行，只增加注释。

```
$text
```
```

## 如何实现"多个不同动作"（重要）

Bob 不支持一个插件同时注册多个服务，但推荐做法是：

1. 在 Bob「服务」列表中**多次添加「通用 AI 处理器」**
2. 每次添加时起不同的**服务名称**（如「代码解释」「要点提炼」「安全审计」）
3. 分别配置不同的 System Prompt / User Prompt 模板

这样你就可以拥有多个专职的 AI 处理动作，并为它们设置独立的快捷键。

示例：
- 「代码解释」→ 配置解释型 prompt
- 「知识卡片」→ 配置提炼型 prompt
- 「转 Python」→ 配置代码转换型 prompt

## OCR 工作流（截图自动处理）

Bob 支持「截图后自动调用某个翻译服务」：

1. Bob 设置 → 快捷键 → 截图翻译 → 选择你配置好的「通用 AI 处理器」（或「代码解释」服务）
2. 使用截图快捷键后，Bob 会自动 OCR → 调用本插件 → 显示解释结果

与划词处理完全一致，无需额外配置。

## 高级配置建议

- **本地模型（Ollama / LM Studio）**：推荐 `qwen2.5-coder:14b`、`deepseek-r1:14b` 等，temperature 设 0.2-0.4
- **Reasoning 模型**（DeepSeek-R1、Qwen3、o1 系列）：插件会自动提取 `reasoning_content` 并显示在 Bob 的「思考过程」区域
- **Temperature**：代码/分析类任务建议 ≤ 0.4，创意重写可提高到 0.8
- **Max Tokens**：复杂代码建议 3000+，注意模型上下文长度限制

## 变量列表

在 User Prompt 模板中可使用以下变量：

| 变量            | 含义                        |
|-----------------|-----------------------------|
| `$text`         | 用户选中的原文（最重要）    |
| `$from`         | 用户选择的源语言            |
| `$to`           | 用户选择的目标语言          |
| `$detectFrom`   | Bob 实际检测到的源语言      |
| `$detectTo`     | Bob 实际检测到的目标语言    |
| `$date`         | 当前日期（YYYY-MM-DD）      |
| `$time`         | 当前时间                    |
